# 나의 요리노트 — 설치 안내

## 1. 올리기 (GitHub Pages, 무료)
1. github.com 가입 → New repository → 이름 `recipe-book`, Public, Create
2. "uploading an existing file" 클릭 → 이 폴더의 파일 5개(index.html, manifest.json, sw.js, icon-192.png, icon-512.png)를 끌어다 놓고 Commit
3. Settings → Pages → Branch: main / (root) → Save
4. 1~2분 뒤 `https://<아이디>.github.io/recipe-book/` 주소로 접속

## 2. 폰에 설치
- 아이폰: Safari로 열기 → 공유(□↑) → "홈 화면에 추가"
- 안드로이드: Chrome으로 열기 → ⋮ 메뉴 → "앱 설치" 또는 "홈 화면에 추가"

## 참고
- 데이터는 각 폰 안에 저장됩니다(기기 간 자동 동기화 없음).
- 파일을 수정해서 다시 올리면 앱을 두 번 정도 다시 열었을 때 반영됩니다.
